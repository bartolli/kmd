# Primer

## Current Focus

What we're working on right now. 1–3 sentences. Not a history log —
progress lives in plan checkboxes; history lives in git.

## Open Questions

Currently-open questions only. Strip on resolution; reflect the
resolution in the relevant ADR or spec, not here.

-

## Blocked On

Nothing currently. List only items genuinely blocking forward
progress.

## Load-bearing invariants (optional)

Facts not derivable from code or commits — pipeline orderings, sync
constraints, file-location rationales. The kind of fact a fresh-context
agent would otherwise re-derive incorrectly. Durable across sessions.

## Read Order (optional)

≤5 entries. Wiki/doc pointers — what to read to orient. Each entry
one line: `[[wikilink]] — why`.

1.

## Working set (optional)

≤10 entries. File pointers (code, fixtures, configs) for the
immediate Next Steps, with one-line context. Lets a fresh-context
agent skip the discovery loop. Task-scoped — refresh when focus
shifts. Most valuable when transitioning phases or starting a new
feature; can be skipped mid-slice when the immediate context already
carries it.

- `path/to/file` — why it's relevant for the next steps.
